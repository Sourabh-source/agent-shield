# Security Policy

## Supported Versions
Currently, only the latest release of AgentGuard is supported with security updates.

## Vulnerability Disclosure Policy
We take the security of AgentGuard seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

### How to report vulnerabilities
Please report suspected security vulnerabilities by emailing:
**security@agentguard.dev**

Do not file public issues for security vulnerabilities.

### Expected Response Timeline
- **Acknowledgment**: Within 48 hours of receipt.
- **Triage**: Within 5 business days.
- **Resolution**: Varies based on complexity, but we aim for within 30-90 days for critical issues.

### Scope
- The AgentGuard backend and middleware
- Tool sandbox implementations
- Cryptographic verification mechanisms

*Out of Scope:*
- Vulnerabilities in third-party dependencies (unless they can be uniquely exploited via AgentGuard).
- Attacks requiring physical access to the server.

### Safe Harbor
We will not pursue legal action against researchers who discover and report vulnerabilities in accordance with this policy. Ensure you do not disrupt services or access user data during your research.

### Contact Information
For all security-related inquiries: security@agentguard.dev
